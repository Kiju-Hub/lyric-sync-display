# lyric-sync-display

지금 PC에서 재생 중인 노래를 자동으로 감지하고, 동기화 가사를 인터넷에서 찾아와 ESP32 + OLED 디스플레이에 실시간으로 보여주는 임베디드 프로젝트입니다.

노래 제목도, 가사 파일도 따로 입력할 필요 없이 — Spotify나 YouTube에서 평소처럼 음악을 틀기만 하면 알아서 가사가 뜹니다.

## 이게 뭘 하는 물건인가요

1. PC에서 지금 재생 중인 곡(제목/아티스트/재생 위치)을 자동 감지
2. LRCLIB에서 동기화 가사(타임스탬프 있는 LRC)를 자동 검색
3. 실제 재생 위치에 맞춰 가사를 계산
4. USB 시리얼로 ESP32에 전송
5. OLED 화면에 애니메이션 배경(막대/파도/턴테이블)과 함께 표시

가사가 없는 곡이어도 음악 재생 자체에는 전혀 지장이 없습니다 — 이 장치는 어디까지나 "있으면 좋은" 보조 디스플레이입니다.

## 아키텍처

```
Spotify / YouTube (재생)
        │
        ▼
Windows Now Playing API (GSMTC)
        │  제목 / 아티스트 / 재생 위치
        ▼
┌─────────────────────────────┐
│   PC Python App (pc_app/)    │
│                              │
│  now_playing.py  ─ GSMTC 폴링│
│  lyrics.py       ─ LRCLIB    │
│                    검색+캐시  │
│  lrc_sync.py     ─ 타이밍 계산│
│  serial_comm.py  ─ 시리얼 전송│
└─────────────────────────────┘
        │ USB Serial ("LYRIC|..." / "TITLE|...")
        ▼
┌─────────────────────────────┐
│  ESP32 Firmware (src/)       │
│  U8g2 + SH1106 OLED          │
│  - 텍스트 줄바꿈/중앙정렬     │
│  - 배경 애니메이션 3종        │

│  - 버튼으로 배경 전환         │
└─────────────────────────────┘
```

## 개발하면서 실제로 부딪힌 문제들

결과물만 보면 단순해 보이지만, 여기까지 오는 동안 겪은 문제들이 이 프로젝트의 진짜 내용입니다.

### 1. GSMTC 재생 위치가 "멈춰있는" 것처럼 보이는 버그
Windows의 재생 위치 API는 4~5초에 한 번씩만 값을 갱신합니다. 그 사이엔 같은 값을 반복해서 돌려주는데, 처음엔 이걸 모르고 매 폴링마다 monotonic 타이머를 리셋하는 코드를 짜서 — 결과적으로 위치 추정이 거의 안 흐르고 GSMTC가 실제로 값을 갱신하는 순간에만 큰 폭으로 점프하는 버그가 있었습니다. 그 결과 짧은 가사 줄(3~4초짜리)이 통째로 점프에 묻혀 화면에 아예 안 뜨는 증상으로 나타났고, 원인을 추적해서 "raw 값이 실제로 바뀔 때만 앵커를 재조정"하도록 고쳤습니다.

### 2. 유튜브 영상은 아티스트명이 채널명으로 잡힘
유튜브에서 재생하면 GSMTC의 "아티스트" 필드에 실제 가수가 아니라 업로드한 채널 이름이 들어오는 경우가 많았습니다. 대신 진짜 "아티스트 - 곡명"은 영상 제목 문자열 안에 그대로 들어있길래, 제목에 " - "가 있으면 그걸 잘라서 한 번 더 검색을 시도하는 폴백을 추가했습니다.

### 3. 한글 아티스트명이 DB에 다른 이름으로 등록되어 있음
일부 국내 아티스트는 가사 DB에 한글 이름이 아니라 공식 영문 표기로만 등록되어 있어서 검색이 실패했습니다 (이름 문제인지, 애초에 DB에 곡 자체가 없는 건지 구분하는 것부터가 디버깅이었습니다). 확장 가능한 별칭 테이블을 만들어 해결했습니다.

### 4. 한글 폰트가 다 지원되지 않음
처음 쓴 폰트가 574개 글자만 지원해서 흔한 음절도 깨졌습니다. 더 많은 글자를 지원하는 폰트로 교체하고, 그래도 안 되는 곡을 위해 화면 크기에 맞는 더 작은 폰트로 다시 교체했습니다.

### 5. 마이너 아티스트는 동기화 가사 자체가 없음
LRCLIB 같은 무료 DB에 아예 등록이 안 된 아티스트도 있었습니다. 다른 상용 API는 이용 약관상 이런 용도로 못 쓰거나 유료였고, 크롤링은 저작권 문제가 있어 배제했습니다. 대신 사용자가 직접 가진 가사에 실제 재생 위치 기준으로 타이밍을 찍어 로컬 캐시에 등록하는 보조 도구를 따로 만들었습니다.

### 6. 배경 애니메이션 여러 번 갈아엎음
막대 그래프 → 파도 → 도시 야경 → 턴테이블까지, 128×64 흑백 1비트 화면 안에서 "평면적이지 않고 입체감 있게" 보이도록 여러 번 웹 미리보기로 시안을 만들고 피드백을 받아 다듬었습니다. 흑백 디스플레이에서 디더링으로 명암을 표현하는 방법, 회전/움직임을 자연스럽게 보이게 하는 방법 등을 시행착오로 찾아갔습니다.

## 하드웨어

- ESP32 개발보드
- SH1106 128x64 I2C OLED
- 배경 전환용 푸시버튼 (GPIO4, 내부 풀업)
- (진행 중) PAM8403 앰프 모듈 + 모노 스피커 4Ω 3W — 블루투스 스피커 기능 추가 예정

## 프로젝트 구조

```
embeded_lirics/
├── src/
│   └── main.cpp          # ESP32 펌웨어 (U8g2, 시리얼 프로토콜, 배경 애니메이션)
├── pc_app/
│   ├── main.py            # 전체 파이프라인 실행 (now playing → 가사 검색 → 전송)
│   ├── now_playing.py     # Windows GSMTC 조회
│   ├── lyrics.py          # LRCLIB 검색 + 정규화 + 별칭 + 로컬 캐시
│   ├── lrc_sync.py        # LRC 파싱 + 재생 위치 기반 타이밍 계산
│   ├── serial_comm.py     # ESP32로 시리얼 전송
│   ├── config.py          # 조절 가능한 설정값
│   ├── tools/              # 수동 가사 등록/타이밍 도구
│   └── steps/               # 단계별 독립 테스트 스크립트
├── wokwi_sim/              # Wokwi 시뮬레이션용 파일
└── platformio.ini
```

## 실행 방법

```powershell
# PC 쪽 (Windows, Python 3.12+)
pip install winsdk requests pyserial
py -3 pc_app/main.py

# ESP32 쪽 (PlatformIO)
pio run --target upload
```
